Como instalar no Android

  1. Os arquivos deste pacote precisam ser publicados em um endereço HTTPS para permitir instalação como aplicativo e atualização offline.
  2. Depois de publicado, abra o endereço no Chrome do celular e escolha Instalar app ou Adicionar à tela inicial.
  3. Abra o aplicativo ao menos uma vez com internet antes de usá-lo offline.

Esta versão armazena os registros localmente no navegador do aparelho. Ela não sincroniza automaticamente entre celulares ou com um computador. Use o backup JSON para guardar uma cópia.
